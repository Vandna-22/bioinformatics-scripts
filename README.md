# Bioinformatics Scripts

This repository contains bioinformatics scripts developed for academic and research purposes.

## Overview
The scripts included in this repository are intended for:
- Data preprocessing
- Statistical analysis
- Visualization of biological data
- Reproducible bioinformatics workflows

## Tools & Languages
- R
- Python
- Command-line bioinformatics tools

## Included Scripts
- `scripts/correlation_network_plot.R`: Builds a community-style correlation network from a CSV edge list, filters by correlation threshold, detects functional communities, and exports both filtered edges (`network_edges.csv`) and a high-resolution figure (`network_plot.png`). The plot uses community-colored nodes, red/blue correlation-direction edges, degree-based node sizing, genus-specific node highlights (so different genera remain visually distinct), and emphasized genus-only labels (bold/italic).

## Intended Use
These scripts are suitable for MSc-level projects, thesis work, and research analysis.
